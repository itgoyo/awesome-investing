## awesome-investing：投资/金融/Web3 学习资料库

- 起因：用户先给了一份「30 个高星仓库」清单，要求汇总成项目并下载书籍。核验后只有 10 个真实存在，20 个 404，星数普遍不符（xiawu/awesome-finance 标 390 实际 8；greyblake/humble-investing 标 240 实际 57）。随后用户改口径：要 GitHub 上 star 最多的 30 个「纯资料汇总」仓库，覆盖投资、金融、web3、理财。
- 结论：重查得到 30 个仓库，全部 GitHub API 核验（存在、未归档、README 可访问、三年内有提交），按 star 排序。最大的是 wilsonfreitas/awesome-quant 30.7k。排除高星但是代码/软件的项目：FinRL 17k、machine-learning-for-trading 21.9k、quant-trading 11.3k。也排除了同名的图库 awesome-stock-resources 和密码学清单。
- 书籍：下载 21 本 29 个文件 231MB。来源两个仓库 codeman008/Financial_freedom（17 本中文经典）与 xiaolai/regular-investing-in-box（中英双语 PDF/EPUB/MOBI + 法西俄日译本）。
- 结构：`data/upstream.json`（API 快照）→ `scripts/build_repos.py` → `data/repos.json`；`scripts/fetch_books.py` 下载并记录真实字节数与 sha256 → `data/books.json`；`build_catalog.py` 生成 `data/catalog.js` 供 `index.html` 使用；`build_readme.py` 渲染双语 README。
- 页面：暗色，中英切换（localStorage + `?lang=en`），搜索、分类筛选、格式按钮直接下载。`file://` 直接打开可用，因为数据走 script 标签而不是 fetch。
- 截图验证用 Playwright 的 chrome-headless-shell：`--no-sandbox --disable-gpu --use-gl=angle --use-angle=swiftshader`，否则 GPU 进程崩溃。
